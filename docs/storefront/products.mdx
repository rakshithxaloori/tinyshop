[Products](/api-reference/storefront/products) describe specific goods or services you offer to your customers. Products have Options & Variants.

[Variants](/api-reference/storefront/variants) are different customizations of the product. [Options](/api-reference/storefront/options) provide the customer to choose among different Variants. For example, _Color_ and _Size_ are Options and a _Red M-sized T-shirt_ is a Variant.

<Note>A customer always buys a specific variant of a product.</Note>

<Note>A product may have only one variant.</Note>

## Add a Variant and its Price

[Variants](/api-reference/storefront/variants) have two kinds of [Prices](/api-reference/storefront/prices) - one_time and recurring.

<Note>You may create Variants without any Options.</Note>

<CodeGroup>
```javascript javascript
const variant = await tinyshop.variants.create({
    name: "Mango",
    options: "Flavor:Mango,Quantity:1 kg",    // (Optional)
    active: true,
    next_refill: 1723353381,    // (Optional) Timestamp of inventory refill, in seconds
    is_default: true,
})

// Add a price
const onetime_price = await tinyshop.prices.create({
variant: variant.id,
active: true,
currency: "INR",
type: "one_time",
unit_amount: 200000, // 2000 INR in paise
is_default: true,
})

````
</CodeGroup>

## Variant with Options

Each Option is a Product's dimension.

<Note>You don't need to create Options to create Variants.</Note>

<CodeGroup>
```javascript javascript
const flavorOption = await tinyshop.options.create({
    product: product.id,
    name: "Flavor",
    values: ["Mango", "Chocolate", "Kit Kat"],
});

const quantityOption = await tinyshop.options.create({
product: product.id,
name: "Quantity",
values: ["500 gms", "1 kg"],
})

````

</CodeGroup>

That's it. You have everything you need for the Product page in your storefront.
