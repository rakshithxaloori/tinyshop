title: "Add a Review"
---

[Reviews](/api-reference/orders/reviews) and ratings for your products.

## Create a Review

```javascript javascript
const review = const tinyshop.reviews.create({
    customer: "cus_xxxaaa",
    product: "prod_xxxbbb",
    feedback: "high_quality",
    product_rating: 4,  // Out of 5
    shipping_rating: 4,     // Out of 5
    review: "The protein powder is great. Very light on the stomach.",
});
```
