---
title: "Create a Variant"
openapi: "POST /v1/variants/{variant_id}"
---

<RequestExample>

```javascript javascript
const variant = await tinyshop.variants.create({
  product: "prod_xxx_aaa",
  name: "Red Cybertruck",
  active: true,
  accept_zero_inventory_orders: true,
  next_refill: Math.floor(Date.now() / 1000), // Current timestamp in seconds
  is_default: true,
});
```

</RequestExample>
