## Authentication

All API endpoints are authenticated using Basic auth with the secret key.

```curl curl
curl https://api.tinyshop.me/v1/products \
  -u sk_test_tR3PYbcVNZZ796tH88S4VQ2u:
# The colon prevents curl from asking for a password.
```
