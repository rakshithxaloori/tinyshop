## Setting up

The first step to get your secret key from the [dashboard](https://dashboard.tinyshop.me) and initialize Tinyshop.

<Note>
  Treat your secret key as a password. Never expose it to the public internet
  directly.
</Note>

```javascript javascript
import Tinyshop from "@tinyshop/tinyshop-node";

const secretKey = process.env.TINYSHOP_SECRET_KEY;

const tinyshop = new Tinyshop(secretKey);
```

## Getting hands dirty

Install our NodeJS SDK

```bash bash
yarn add @tinyshop/tinyshop-node
```

Create your first product

```javascript javascript
const newProduct = await tinyshop.products.create({ name="Model S" });
```
