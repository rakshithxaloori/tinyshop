---
title: "Collections"
description: "A Collection is a group of products that are of the similar type or functionality."
---

## Create a Collection

```javascript javascript
const collection = await tinyshop.collections.create({
  name: "Protein Powders",
  products: ["prod_xxxaaa", "prod_xxxbbb"],
});
```

<Note>A Product can belong to multiple Collections.</Note>

Upon creation, every collection has [a collection handle](/api-reference/store/collections/create) you can use for the collection's storefront page, at _/collection/:collection_handle_, for example.
